# 🐄 Farm Management System

## Overview

The Farm Management System is a web-based application developed to help farms efficiently manage animal records and daily operations. The system provides secure user authentication and role-based access, ensuring that different users have access only to the features relevant to their responsibilities.

The application allows administrators to maintain accurate animal records, while farmers can easily view animal information through a simple and user-friendly interface.

---
# Project Objective

The objective of this project was to strengthen my understanding of ASP.NET Core MVC, Entity Framework Core, SQL Server, and Object-Oriented Programming by developing a secure database-driven web application with user authentication and CRUD functionality.

---
## Features

### Administrator
- Secure login
- Add new animal records
- View all animal records
- Update existing animal information
- Delete animal records
- Manage the farm database

### Farmer
- Secure login
- View animal records
- Search for animals
- Access animal information in a read-only format

## Installation

1. Clone the repository

```bash
git clone https://github.com/Tshepo-mahao-hub/FarmManagementSystem.git
```

2. Open the solution in Visual Studio.

3. Restore NuGet packages.

4. Update the SQL Server connection string in `appsettings.json`.

5. Run the database migrations.

6. Press **F5** to start the application.
